# tic-tac-toe

A neon, mobile-first tic-tac-toe game built with React and Vite.

## Features

- Play against a **Chill CPU**, an unbeatable **Sharp CPU**, or a friend on the same phone
- Fullscreen, distraction-free game mode on mobile
- Round scores, win streaks, and a saved personal best
- Keyboard support: `1`–`9` to place a mark, `R` for a new round
- Responsive layout for desktop, tablet, and phone

## Run locally

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```

## Tech

React, Vite, and lucide-react.
